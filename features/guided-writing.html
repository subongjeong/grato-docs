질문으로 쓰기 ​

"질문으로 쓰기"는 무엇을 써야 할지 모를 때 질문에 답하며 감사 글을 시작하는 작성 모드입니다. 질문은 운영자가 선정한 질문(기본 질문 + 사용자가 제안해 선정된 질문)에서 고릅니다. 답변과 초안 만들기는 모두 기기 안에서 이루어지고, 작성 내용은 사용자가 저장할 때 일반 글 저장 경로로만 Firestore에 올라갑니다. → 결정 기록 #10, #11

흐름 ​

  1. 첫 번째 질문 — 첫 질문 풀에서 무작위로 하나를 보여 줍니다. 질문을 불러오는 동안은 자리 표시만 보입니다. 답을 써야 다음으로 넘어갑니다.
  2. 두 번째 질문 — 이어지는 질문 풀에서 하나를 보여 줍니다. 답하거나 "이 질문은 건너뛸게요"로 바로 초안을 만들 수 있습니다.
  3. 초안 — 답변을 빈 줄로 이어 붙여 내용에 넣고, 제목은 비워 둡니다.
  4. 저장 — 제목과 내용이 모두 있어야 저장 버튼이 켜집니다. 공개 범위는 기본이 "나만 보기"이고(버튼 "저장하기"), "Circle에 공유"를 고르면 Circle을 골라야 저장할 수 있습니다(버튼 "Circle에 공유하기"). → 공개 범위

질문 카드의 "다른 질문"을 누르면 같은 풀에서 지금 질문과 다른 질문으로 바꿉니다. 사용자가 제안해 선정된 질문에는 "💡 홍길동 #1234님의 질문"처럼 제안자의 공개 이름이 함께 보입니다(기본 질문이나 이름이 없는 질문은 표시하지 않음). → 제안자 표시

질문 화면 아래의 "좋은 질문이 떠올랐나요? 질문 제안하기"로 질문을 제안할 수 있습니다. → 질문 제안과 선정

질문 풀 ​

질문은 운영자가 선정한 질문에서 고르고, 그것을 읽지 못하면 앱에 들어 있는 기본 질문 목록으로 대신합니다.

출처위치설명
선정된 질문questions (status == "approved")기본 질문(source: "system") + 사용자가 제안해 선정된 질문(source: "user")
앱 안의 기본 질문src/content/questions.json{ "opening": [30개], "followup": [10개] }. seedQuestions 스크립트가 같은 파일을 Firestore의 system_* 문서로 넣음

src/lib/questionApi.js의 loadQuestionPools()가 풀을 만듭니다.

  • 선정된 질문을 세션에 한 번 읽습니다(where('status', '==', 'approved'), 최대 500개, 정렬 없음). 그래서 새로 선정된 질문은 다음에 앱을 열 때부터 나옵니다.
  • 읽기에 실패했거나 오프라인 캐시에서 온 결과는 저장하지 않아 다음에 다시 읽습니다. 4초 안에 오지 않으면 앱 안의 목록으로 먼저 시작합니다.
  • buildQuestionPools()가 종류(kind)별로 나눕니다. 어떤 종류에 선정된 기본 질문이 하나도 없으면(시드 전, 읽기 실패) questions.json의 목록에 선정된 사용자 질문을 더해 씁니다. 사용자 질문 몇 개가 기본 질문 전체를 대신하지 않게 하기 위해서입니다.
  • 같은 문구(공백·구두점·보이지 않는 문자를 빼고 같은 것)는 한 번만 넣습니다.
  • 숨긴 질문(hidden)은 풀에 들어가지 않습니다.

src/content/questions.js는 JSON을 import할 뿐 React·Firebase를 import하지 않는 순수 모듈이라 node:test로 바로 테스트합니다(questions.test.js).

함수동작
buildQuestionPools(approved)선정된 질문을 { opening, followup }으로 나눔 (위의 대체 규칙 포함)
pickQuestion(pool, exclude?)풀에서 무작위로 하나. exclude(지금 보이는 질문)는 다른 선택지가 있으면 고르지 않음
buildDraftContent(answers)답변의 앞뒤 공백을 지우고, 빈 답변을 빼고, 빈 줄(\n\n)로 이어 붙임
questionCredit(question)사용자 질문의 "💡 {이름}님의 질문" 문구
normalizeQuestionText, questionTextError서버와 같은 정규화와 5~80자 확인 (질문 제안·운영자 수정에 사용)
QUESTION_POOL, FOLLOWUP_POOLquestions.json의 opening, followup (따로 복사해 두지 않음)

기본 질문을 추가·수정할 때는 questions.json을 고치고, 배포 때 seedQuestions를 실행합니다. 이어지는 질문은 첫 질문과 상관없이 고르므로 어떤 첫 질문 뒤에 와도 자연스러운 문장으로 씁니다. → 기본 질문

길이 제한 ​

항목제한
답변 하나1000자 (두 답변과 빈 줄을 합쳐도 내용 한도 안)
제목1~100자 (화면에서 필수, 규칙은 0~100자)
내용1~3000자

화면 문구 ​

질문으로 쓰기의 문구는 "질문", "답변", "초안"으로 기능을 설명합니다. 사용자에게 보이는 문구에는 "AI"나 "인공지능"이라는 표현을 쓰지 않습니다.
