공지 ​

운영자가 서비스 소식, 약관·개인정보처리방침 변경 안내를 올리는 공지입니다. 누구나(로그인하지 않아도) 읽을 수 있고, 쓰기는 운영자만 서버 함수로 합니다.

사용자 화면 ​

  • 홈 배너: 운영자가 "홈 배너"로 올린 공지 중 가장 최근 것이 홈 맨 위(앱 설치 안내 위)에 "공지 · 제목"으로 보입니다. 누르면 공지 화면, X로 닫으면 이 기기에서는 다시 보이지 않습니다(localStorage, 공지마다). 홈이 그려진 뒤 세션에 한 번 최근 공지 5개를 읽습니다(시작을 막지 않음, ADR-13).
  • 공지사항 (/notices): 설정 › 공지사항. 최근 30개, 최신순. /notices/{id}는 공지 하나(줄바꿈 그대로).
  • 약관·처리방침을 바꿀 때 시행일 7일 전(중요한 변경은 30일 전) 서비스 안 공지가 이 공지입니다. → 약관

운영자 화면 ​

관리자 › 공지 탭: 제목(1~60자)·내용(1~3000자, 줄바꿈 유지)·"홈 화면 위에 배너로 보여주기"를 쓰고 [공지 올리기]. 올린 공지는 아래 목록에서 고치기·삭제합니다. 올리는 즉시 모두에게 보입니다.

데이터와 함수 ​

항목내용
문서notices/{id} = { title, body, banner, publishedAt, updatedAt }. 올린 운영자는 문서에 없고 adminAuditLogs에만 남음
규칙읽기 누구나, 쓰기 거부(운영자 포함)
쓰기callable manageNotice({action: create·update·delete, id?, title, body, banner}) — isAdmin 확인, 글자 정리(notices/text.ts, 제목 한 줄·내용 빈 줄 최대 하나), 같은 배치에서 adminAuditLogs(notice_create·notice_update·notice_delete) → Cloud Functions
