프로젝트 개요 ​

Grato는 하루의 감사를 기록하고, Circle(소규모 그룹)의 가까운 사람들과 나누는 커뮤니티 앱입니다. 웹(grato.today)으로 운영 중이며, Capacitor로 iOS·Android 앱 출시를 준비하고 있습니다. 모든 화면과 메시지는 한국어가 기본입니다.

주요 기능 ​

영역기능자세히
작성질문으로 쓰기(선정된 질문에 1~2개 답하면 답변으로 초안을 만듦), 직접 작성 모드. 기본은 "나만 보기", Circle 공유는 선택질문으로 쓰기, 감사 글과 공유
질문 제안사용자가 질문을 제안하고 운영자가 선정. 선정된 질문에 제안자 표시, 알림·배지질문 제안과 선정
홈 피드"내 기록"(기본 탭) + Circle별 실시간 피드감사 글: 내 기록
Circle비공개 소규모 그룹. 생성·초대 코드로 참여·탈퇴·멤버 내보내기·삭제Circle
반응이모지 리액션 4종(❤️ 🙏 ✨ 🔥), 댓글감사 글과 공유
공유작성자가 공개한 감사 글·캘린더 월·배지만 공유 링크로 노출, OG 메타감사 글과 공유
알림FCM 웹 푸시: Circle 새 글, 리액션, 매일 알림(KST), 질문 선정알림
기록연속일·월별 통계(KST), 캘린더 PNG 내보내기, 배지, 글 삭제통계와 배지
안전신고, 차단, 욕설·혐오 표현 자동 숨김, 관리자 신고 처리신고·차단과 자동 숨김
계정Google·Apple·이메일 로그인, 약관 동의와 만 14세 이상 확인, 앱 안 계정 삭제계정
기타PWA 설치 배너, SEO 랜딩 페이지, 약관·고객지원 페이지, 피드백, 관리자 페이지(신고·질문 검토·배지·분석)클라이언트

구분사용 기술
프론트엔드React 18, Vite 5, Tailwind CSS 3, Zustand, React Router 6, lucide-react
백엔드Firebase Auth, Cloud Firestore, Cloud Storage, Hosting, Cloud Functions v2(Node 22), Cloud Messaging
테스트node:test, @firebase/rules-unit-testing + Firebase 에뮬레이터

설계 원칙 한눈에 보기 ​

  • 권한이 걸린 쓰기는 서버가 한다. Circle 멤버십, 통계, 배지, 댓글 수, 질문 제안·검토는 Admin SDK를 쓰는 Cloud Functions만 바꿉니다. 클라이언트는 보안 규칙이 허용하는 좁은 형태의 쓰기만 합니다. → 보안 규칙
  • 작성자 정보는 위조할 수 없다. 글·댓글의 작성자 필드는 publicProfiles/{uid}와 일치해야 하고, 공개 이름(이름 #태그)은 전역에서 유일합니다.
  • 기록은 기본이 나만 보기. 새 감사 글은 개인 기록이고, Circle 공유는 글을 쓸 때 직접 고릅니다. → 결정 기록 #12
  • 외부 공유는 작성자가 고른 것만. 공유 링크는 작성자가 공개한 글·캘린더 월·배지만 보여 줍니다.
  • 다른 사람에게 보이는 질문은 사전 검토. 제안한 질문은 운영자가 선정한 것만 보입니다. → 결정 기록 #11
  • 그 밖의 공유 콘텐츠는 신고·차단·자동 숨김. "나만 보기" 글은 운영자도 보지 않습니다. → 결정 기록 #14
  • 계정 삭제는 삭제가 기본. 다른 사람에게 의미가 생긴 것만 연결을 끊어 남깁니다. → 결정 기록 #15
  • 날짜는 KST 기준. 연속일·월별 통계와 매일 알림은 모두 한국 시간으로 계산합니다.
  • 클라이언트·함수·규칙은 한 세트. 셋이 맞물려 있어 항상 함께 배포합니다. → 배포
