1단계 — 보안·안정화 ​

서버가 권한을 책임지는 구조로 정리하고, 테스트로 고정한 단계입니다.

  • Circle 생성·참여·탈퇴·내보내기·삭제·초대 코드 재발급을 callable 함수로 이전 → Circle
  • 작성자 필드를 공개 프로필과 대조, 공개 이름(이름 #태그) 전역 유일 → 보안 규칙
  • 외부 공유를 작성자 opt-in으로 → 감사 글과 공유
  • 통계(연속일·월별)를 서버에서 KST로 계산, 트리거 멱등성 → 통계와 배지
  • AI 글쓰기 기능을 없애고 기기 안의 질문 풀로 동작하는 질문으로 쓰기로 대체 → 질문으로 쓰기
  • 보안 규칙 테스트, 함수·클라이언트 단위 테스트 → 테스트

배포는 클라이언트·함수·규칙을 함께 올리는 순서가 중요합니다. → 배포

질문 제안·선정, 개인 기록 기본값 ​

1단계 다음에 진행한 기능 작업으로, 2026-10-08에 배포했습니다. → 변경 이력

  • 감사 글은 기본이 "나만 보기"이고, Circle 공유는 글을 쓸 때 직접 고름. 홈 첫 탭은 "내 기록" → 공개 범위, 결정 기록 #12
  • 질문으로 쓰기의 질문을 사용자가 제안하고 운영자가 선정. 선정된 질문에 제안자 표시, 알림과 배지 → 질문 제안과 선정, 결정 기록 #11
  • 제안 질문은 운영자가 선정하기 전에는 다른 사용자에게 보이지 않음(사전 검토). 내용 필터는 2단계의 자동 숨김에서 다시 씀 → 출시 준비 체크리스트
  • 배포는 서버 → 기본 질문 시드 → 클라이언트 순서 → 배포

2단계 — 스토어 필수 기능 ​

스토어 심사 정책상 앱 출시 전에 반드시 있어야 하는 기능입니다. 코드와 테스트(규칙·단위·에뮬레이터 엔드투엔드)는 끝났고 배포를 앞두고 있습니다. → 변경 이력, 배포

기능상태내용
Sign in with Apple✅ 웹Google과 같은 크기로 나란히 배치, 이메일 가리기 허용. 콘솔 설정은 배포 때 → 계정
약관 동의와 만 14세 이상 확인✅가입 폼·동의 화면, 규칙이 글·댓글 생성 때 동의 기록 확인 → 약관 동의
앱 안에서 계정 삭제✅재인증 → Apple 연결 해제 → 서버 삭제·익명화. 공개 삭제 안내 URL → 계정 삭제, 결정 기록 #15
신고·차단✅글·댓글·멤버·Circle 신고, 차단, 욕설·혐오 표현 자동 숨김, 관리자 신고 처리 화면과 운영자 푸시 → 신고·차단과 자동 숨김, 결정 기록 #14
감사 글 삭제✅작성자 삭제, 댓글·통계·공유 월은 트리거가 정리 → 감사 글: 삭제
약관·개인정보 처리방침, 고객지원✅전면 개정, /support, /account-deletion. 시행일은 배포 전에 입력 → 출시 준비 체크리스트

배포 전에 남은 일: Apple 로그인 콘솔 설정, 약관 시행일 입력, Firestore 시점 복구(PITR) 확인, 운영자 기기 알림 켜기. → 이번 릴리스 배포

3단계 — Capacitor 포팅 ​

웹 앱을 네이티브 셸에 담고, 웹뷰에서 동작하지 않는 부분을 네이티브 플러그인으로 바꿉니다. 웹사이트는 그대로 두고 앱 전용 코드는 모두 isNative 분기와 동적 로딩 뒤에 둡니다. 설정·빌드·출시 절차는 iOS·Android 앱에 있습니다. → 변경 이력

작업상태내용
Firebase JS SDK 10 → 12✅Capacitor 인증 플러그인 요구 사항
iOS·Android 프로젝트✅cc.mknw.grato, Capacitor 8.5, iOS SPM, Android target SDK 36. Firebase에 두 앱 등록 → 프로젝트 구성
네이티브 Google·Apple 로그인✅ 코드플랫폼 로그인 화면 → JS SDK 세션, 계정 삭제 재인증·Apple 연결 해제 → 로그인, 결정 기록 #17
네이티브 푸시 (APNs·FCM)✅ 코드서버가 앱 토큰에 notification 페이로드. iOS는 APNs 키 등록 필요 → 푸시
휴대폰 자체 매일 알림✅ 코드14일 치 로컬 알림, 서버 알림과 겹치지 않게 dailyReminderChannel → 매일 알림, 결정 기록 #16
링크로 앱 열기✅ 코드Universal Links / App Links, /.well-known 파일. 출시용 SHA-256은 출시 때 → 링크로 앱 열기
공유 시트, 안전 영역, 상태 표시줄, 스플래시, 키보드, 뒤로 가기✅ 코드→ 화면 처리
앱 아이콘✅ 완료새싹 마크 + Fraunces 로고 글자 → 아이콘과 브랜드
실제 기기 확인⬜iPhone·Android에서 출시 체크리스트의 확인 항목
서버·Hosting 배포, APNs 키⬜앱 빌드를 나눠 주기 전에 → 서버·Hosting 먼저 배포

4단계 — 스토어 제출 ​

  • 스토어 등록 정보(스크린샷, 설명, 개인정보 라벨/데이터 보안 섹션)
  • 심사용 테스트 계정과 심사 메모
  • 개인정보처리방침·이용약관 최신화
  • 출시 준비 체크리스트는 출시 준비 체크리스트에서 관리합니다.
