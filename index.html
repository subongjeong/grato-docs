아키텍처

React + Firebase 구성, 데이터 모델, 보안 규칙, Cloud Functions, 클라이언트 구조

기능

기본은 나만 보는 감사 기록, Circle 멤버십과 opt-in 공유, 알림, 질문으로 쓰기와 질문 제안·선정, 통계와 배지, 신고·차단, 계정

운영

서버 → 기본 질문 시드 → 클라이언트 순서의 배포, 세 가지 테스트, 출시 준비 체크리스트

모바일 앱

Capacitor로 만드는 iOS·Android 앱 — 빌드와 실행, 네이티브 로그인, 푸시, 휴대폰 자체 알림, 링크로 앱 열기, 출시 체크리스트

결정 기록

왜 이렇게 만들었는지 — 주요 설계 결정과 검토한 대안
