사용자와 신원 ​

users/{uid} — 비공개 사용자 문서 ​

필드타입쓰는 주체설명
displayNamestring본인표시 이름
emailstring | null본인이메일 (이 문서에만 저장)
photoURLstring | null본인프로필 사진
tagstring본인 (한 번만)숫자 태그. 비어 있을 때만 설정 가능
publicNamestring본인항상 `${displayName} #${tag}`
groupIdsstring[]서버참여 중인 Circle. 생성 시 빈 배열만 허용
createdAttimestamp본인 (한 번만)서버 시간. 이후 변경 불가
notificationSettingsmap본인dailyReminder(기본 true), dailyReminderHour(기본 21), dailyReminderMinute(0·15·30·45, 기본 0), reactionNotice(기본 true), circlePostNotice(기본 true), dailyReminderChannel(앱이 로컬 알림을 맡으면 'local', 아니면 null/없음), dailyReminderLocalAt(그때의 서버 시각) → 알림 설정
consentmap본인약관 동의와 만 14세 이상 확인. 정확히 { termsVersion, ageConfirmed: true, at }(at은 서버 시간). 새 버전에 동의하면 통째로 다시 씀. 지우거나 일부만 고칠 수 없음 → 약관 동의
isAdminbool콘솔/Admin SDK만관리자 페이지 접근, 질문 검토, 신고 처리, 배지 편집

불변식

  • 본인만 읽고 쓸 수 있습니다. 다른 사람의 정보는 항상 publicProfiles로 봅니다(이메일 노출 방지).
  • groupIds는 Circle callable만 바꿉니다. 탈퇴·삭제 후 남은 오래된 ID는 함수가 다음 생성·참여 때 정리합니다.
  • Circle callable이 클라이언트보다 먼저 문서를 만들 수 있습니다(groupIds만 있는 문서). 이 경우 다음 로그인 동기화에서 클라이언트가 createdAt과 알림 설정을 채웁니다.
  • consent가 없거나 termsVersion이 현재 버전(src/content/legal.js의 TERMS_VERSION)과 다르면 클라이언트가 동의 화면을 보여 줍니다. 감사 글·댓글 생성 규칙은 consent가 있는지 확인합니다.
  • 클라이언트는 삭제할 수 없습니다. 계정 삭제는 deleteAccount callable이 하위 컬렉션(blocks)과 함께 지웁니다. → 계정 삭제

users/{uid}/blocks/{blockedUid} — 차단 목록 ​

createdAt(서버 시간) 하나만 가집니다. 문서 ID가 차단한 사용자의 uid입니다.

  • 본인만 읽고, 만들고(자기 자신은 차단 불가), 지웁니다(차단 해제). 다시 차단(setDoc)은 같은 형태의 수정으로 허용됩니다.
  • 클라이언트는 이 목록으로 차단한 사람의 글·댓글을 화면에서 거르고, 알림 트리거(Admin SDK)는 받는 사람이 보낸 사람을 차단했으면 건너뜁니다. 새 차단은 onBlockCreated가 운영자 대기열에 낮은 우선순위 신고로 남깁니다. → 차단

publicProfiles/{uid} — 공개 프로필 ​

필드설명
displayName1~100자
tag1~10자, 한 번 정해지면 변경 불가
publicName`${displayName} #${tag}` — 전역 유일
photoURL본인 Storage 업로드(profilePhotos/{uid}/…) 또는 본인 ID 토큰의 Google 아바타, 또는 null
  • 정확히 이 4개 필드만 가집니다. 로그인한 사용자는 문서 하나씩 get만 할 수 있고 목록 조회는 불가능합니다(사용자 목록 수집 방지).
  • 글·댓글의 작성자 필드(authorName, authorTag, authorPublicName, authorPhotoURL)는 이 문서와 같아야 생성됩니다.
  • displayName이 바뀌면 onPublicNameWritten이 내용 필터로 검사해, 걸리면 이름은 그대로 두고 운영자 대기열에 신고를 남깁니다. → 자동 숨김: 이름
  • 클라이언트는 삭제할 수 없습니다(deleteAccount가 지움). 차단 목록에 남은 삭제된 계정은 프로필이 없어 "알 수 없는 사용자"로 보입니다.

publicNames/{key} — 공개 이름 선점 ​

key는 publicName의 UTF-8 바이트를 SHA-256으로 해시한 소문자 16진수입니다. 클라이언트(src/lib/publicName.js), 함수(functions/src/utils/publicName.ts), 규칙(hashing.sha256)이 같은 계산을 합니다.

필드설명
uid이름을 가진 사용자
publicName원문 이름
  • 먼저 만든 사람이 임자입니다. 생성만 가능하고 덮어쓸 수 없습니다.
  • 자기 프로필이 같은 배치에서 그 이름을 갖게 될 때만 만들 수 있고, 이름을 바꿀 때 예전 선점은 같은 배치에서 지워야 합니다.
  • 프로필·선점·users는 항상 하나의 배치로 함께 씁니다(src/lib/firestore.js).
  • 선점 제도 이전에 만들어진 이름은 backfillPublicNames 스크립트로 선점 문서를 만들어 둡니다. → Cloud Functions

불변식

  • memberIds에는 항상 adminId가 들어 있고, 관리자는 탈퇴·내보내기 대상이 아닙니다.
  • users/{uid}.groupIds와 memberIds는 같은 트랜잭션에서 함께 바뀝니다.
  • 존재하지 않는 Circle 문서에 대한 get은 오류가 아니라 빈 결과를 돌려줍니다. 클라이언트는 이것으로 "삭제된 Circle"과 "권한/네트워크 오류"를 구분합니다.
  • memberIds는 참여 순서입니다(생성자가 처음, 참여는 뒤에 붙음). 계정 삭제 때 관리자를 넘겨받을 "가장 오래 함께한 멤버"를 이 순서로 정합니다.
  • 관리자가 이름·설명을 바꾸면 onCircleNameWritten이 내용 필터로 검사해, 걸리면 운영자 대기열에 신고를 남깁니다(이름은 그대로). 생성 때는 createCircle이 거절합니다.
  • 운영자(users.isAdmin)는 신고된 Circle을 확인하려고 문서 하나를 get할 수 있습니다(목록 조회는 불가).

  • 문서 ID는 클라이언트 자동 ID(영숫자 20자)만 허용됩니다. 서버 마커 ID가 이 값으로 만들어지기 때문입니다.
  • 생성 후 클라이언트가 바꿀 수 있는 것은 ① 리액션(본인 uid 추가·제거), ② 작성자의 isPublic/sharedAt뿐입니다. 서버는 commentCount와 moderation(숨김 때 groupId 포함)을 바꿉니다. 내용·작성자는 아무도 고칠 수 없습니다.
  • 새 글은 기본이 "나만 보기"(groupId: null)입니다. Circle 공유는 작성 화면에서 직접 고를 때만 됩니다. → 공개 범위, 결정 기록 #12
  • 홈의 "내 기록"은 userId == 나 + createdAt 내림차순 쿼리(기존 인덱스)로 개인 글과 Circle에 공유한 글을 함께 읽습니다.
  • 작성자는 Circle을 떠나거나 Circle이 삭제된 뒤에도, 글이 숨겨진 동안에도 자기 글을 읽을 수 있습니다(개인 기록으로 보존).
  • 작성자만 삭제할 수 있습니다. 삭제하면 onGratitudeDeleted가 댓글 하위 컬렉션을 지우고, 통계를 남은 글로 다시 계산하고, 그 달에 글이 남지 않으면 공유한 캘린더 월을 비공개로 돌립니다. 받은 배지는 유지됩니다. → 감사 글: 삭제
  • 생성 규칙은 약관 동의(users.consent)와 계정 잠금이 없는지(disabledUsers)를 함께 확인합니다.
  • 예전 문서에는 isPublic이 없거나 다른 이모지 키가 있을 수 있습니다. 규칙은 이를 허용하되 기존 키는 바꾸지 못하게 합니다.

moderation 필드 ​

글과 댓글에 서버(자동 숨김 트리거, moderate callable)만 쓰는 숨김 기록입니다. 클라이언트는 만들 때도 수정할 때도 이 필드를 쓸 수 없습니다.

필드설명
statushidden | visible (운영자가 숨김을 해제함)
sourceauto(필터) | admin(운영자)
reasonprofanity(필터) 또는 null(운영자)
at서버 시간
groupId글만. 숨긴 동안 원래 Circle ID, 보이는 동안 null
  • status == "hidden"이면 작성자("검토 중이에요")와 운영자에게만 보입니다. → 자동 숨김
  • 숨긴 Circle 글은 groupId가 null이라 Circle 피드 쿼리(groupId ==)에 나오지 않습니다. 화면 표시용 Circle은 circleIdOf()(groupId ?? moderation.groupId)로 구합니다.
  • 기록이 하나라도 있으면 필터는 다시 건드리지 않습니다. 운영자의 결정이 항상 우선합니다.
