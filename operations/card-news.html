SNS 카드뉴스: 오늘의 질문 ​

인스타그램·스레드에 일주일에 세 번(월·수·금) 올리는 "오늘의 질문" 카드뉴스를 만드는 도구입니다. 이미지는 스토어 스크린샷처럼 headless Chrome으로 HTML을 찍어 만들고, 게시는 손으로 합니다. 도구와 자세한 사용법은 resources/marketing-tools/(card-news.mjs, README.md)에 있습니다.

한 게시물의 구성 ​

장내용
1. 표지"오늘의 질문" 표시, 질문(크게), 날짜, 새싹 마크와 로고 글자
2. 답하는 방법질문을 작게 다시, 짧은 안내 한 줄과 세 가지 실마리(누가·언제·무엇이, "덕분에…", 기분을 한 단어로 등)
3. 안내"Grato에서 오늘의 감사를 기록해 보세요", grato.today, "App Store에서 Grato 검색"
  • 크기는 1080×1350(4:5)과 1080×1080(정사각형) 두 가지. 인스타그램 여러 장 게시물은 모든 장을 첫 장의 비율로 자르므로 한 가지 모양으로 세 장을 올립니다
  • caption.txt(인스타그램: 질문, 안내 두 줄, 앱 안내, 해시태그 7개, 2,200자 미만)와 threads.txt(스레드: 더 짧게, 주제 태그 하나, 500자 미만)를 함께 만듭니다
  • 앱과 같은 모습: 크림 배경 #FFF7ED, 흰 카드에 따뜻한 테두리 #F1E4D1, 주황 강조, 본문 Noto Sans KR. 질문과 큰 제목은 스토어 스크린샷과 같은 함렛(Hahmlet), 로고 글자는 도형으로 바꾼 Fraunces Italic(아이콘과 브랜드)
  • 한글 줄바꿈: 단어 중간에서 끊지 않고(keep-all) 줄 길이를 고르게 맞춥니다. "것이", "때" 같은 의존 명사는 앞 단어와 붙여 둡니다. 질문이 길면(제안 질문 최대 80자) 글자 크기를 줄여 맞추고, 가장 작은 크기로도 넘치면 만들지 않고 멈춥니다

문구 원칙 ​

  • 생성형 AI를 쓰지 않습니다(ADR-10). 질문은 운영자가 고른 src/content/questions.json의 "opening" 질문(앱의 기본 질문)이고, 2장의 안내와 캡션 문장은 스크립트 안에 사람이 써 둔 고정 문구입니다. 글이나 이미지에 "AI"·"인공지능"이 들어가면 스크립트가 멈춥니다
  • 사용자가 제안해 선정된 질문(Firestore)은 쓰지 않습니다. 앱에서는 제안자 이름과 함께 보이는 질문이라 SNS에 옮기려면 따로 확인이 필요합니다
  • 별점·순위·사용자 수 같은 주장은 넣지 않습니다
  • Android 앱은 아직 출시 전이라 Google Play는 언급하지 않습니다. 출시하면 3장과 캡션에 추가합니다

질문 순서 ​

  • 2026-W43(첫 게시 주)부터 센 주 번호를 k라 하면, 월요일은 opening 질문 (3k mod N) + 1번, 수요일은 그다음, 금요일은 그다음 질문입니다(N은 opening 질문 수, 지금 45개 — GRATO-93 전에는 30개)
  • 45개를 15주에 한 바퀴 돌고, 이어지는 주끼리는 겹치지 않습니다. 주를 세는 방식이라 53주인 해(2026년)도 상관없습니다
  • 안내 문구 6가지도 같은 방식으로 돌아갑니다
  • opening 질문을 더하거나 빼면 그다음 주들의 순서가 바뀝니다(이미 올린 주는 그대로). --dry-run으로 미리 확인하고, 필요하면 --start N으로 그 주만 시작 질문을 정합니다

시즌 모드 ​

시즌 질문 날짜(11/15–11/30 감사의 계절, 12/1–12/31 한 해 돌아보기, 1/1–1/10 신년 감사)에 올리는 게시물은 그날 앱의 오늘의 질문과 같은 시즌 질문을 씁니다(자동, src/content/seasonQuestions.js). 카드의 "오늘의 질문" 자리에 시즌 이름("감사의 계절", "한 해 돌아보기", "신년 감사"), 캡션 첫 줄도 [한 해 돌아보기] …, 해시태그에 #감사의계절·#한해돌아보기·#새해감사가 하나 더 붙습니다. 안내 문구 순환과 시즌 밖 주의 질문 순서는 그대로입니다.

bash
node resources/marketing-tools/card-news.mjs --week 2026-W47 --dry-run   # 11/16·11/18·11/20: [감사의 계절] …
node resources/marketing-tools/card-news.mjs --week 2026-W49 --dry-run   # 11/30: 감사의 계절, 12/2·12/4: [한 해 돌아보기] …
node resources/marketing-tools/card-news.mjs --week 2026-W53 --dry-run   # 12/28·12/30: 마무리, 1/1: [신년 감사 01]

예고 주(11/9·11·13)의 시즌 질문 미리보기는 자동이 아닙니다(그 주는 기본 순환). 필요하면 그로스가 따로 정합니다.

만들기 ​

필요한 것: Google Chrome, puppeteer-core(앱 의존성에 넣지 않음. 저장소 루트에서 npm i --no-save puppeteer-core), 인터넷(Google Fonts).

bash
node resources/marketing-tools/card-news.mjs --week 2026-W44 --dry-run            # 그 주의 질문만 확인
node resources/marketing-tools/card-news.mjs --week 2026-W44 --out ~/Desktop/grato-card-news
node resources/marketing-tools/card-news.mjs --out ~/Desktop/grato-card-news     # --week를 빼면 이번 주(한국 시간)

<out>/<날짜>/에 1.png·2.png·3.png, 1-square.png·2-square.png·3-square.png, caption.txt, threads.txt가 생깁니다. 결과물은 저장소 밖에 두고 커밋하지 않습니다.

올리기 ​

자동 게시는 하지 않습니다. 인스타그램 Graph API·Threads API로 올리려면 프로페셔널(비즈니스) 계정, Meta 앱과 앱 검수가 필요해 지금은 범위 밖입니다.

  1. --dry-run으로 그 주의 질문을 확인합니다(최근에 손으로 올린 질문과 겹치지 않는지)
  2. 이미지를 만들고 모든 장을 열어 봅니다: 줄바꿈, 잘린 글자, 날짜
  3. caption.txt·threads.txt를 읽고 질문에 어울리지 않는 줄은 손으로 고칩니다
  4. 인스타그램: 1·2·3장을 순서대로(또는 정사각형 세 장) 고르고 원본 비율 그대로, 캡션 붙여 넣기. 고급 설정에서 표지의 대체 텍스트에 질문을 넣습니다. 미리 올려 둘 때는 앱이나 Meta Business Suite의 예약 기능을 씁니다
  5. 스레드: 같은 세 장과 threads.txt
